# Формат карусели — 6 слайдов

**Решение:** 6 слайдов, не 9 (grid Karuselka).

## Почему 6

| Слайдов | Плюсы | Минусы |
|---------|-------|--------|
| 9 (Karuselka 3×3) | много контента | низкий дочитываемость, тяжёлый master |
| 7 | проверенная конверсия | длинно для EMDR-ниши |
| **6** | hook → боль → 2× value → save → CTA | нужен отдельный пайплайн (не 3×3) |

## Архитектура 6 слайдов

```text
01 HOOK        — pattern interrupt, 0.5 сек
02 PAIN        — «это про меня», амплификация
03 INSIGHT     — механизм / «ага-момент» #1
04 PROOF       — шаги, факт, EMDR-рамка
05 SAVE        — чеклист / формула (сохраняют)
06 CTA         — бесплатная пробная 30 мин
```

## Технический формат

- **Master (генерация):** grid 3×2, 3240×2700 → **1 вызов Runware** → нарезка
- **Слайды (публикация):** PNG **1080×1350** (4:5) — см. `profile/platform-dimensions.md`
- Runware `openai:gpt-image@2`, quality **medium**
- Slide-01 может быть **MP4 5s** (немой hook)
- TikTok: Zernio `auto_add_music` + ручная смена трека; IG: музыка вручную в приложении
