# Размеры карусели: Instagram vs TikTok

## Выход пайплайна (после нарезки master 3×2)

| Параметр | Значение |
|----------|----------|
| Master (генерация) | 3240×2700 px (grid 3×2, одна генерация) |
| Каждый слайд | **1080×1350 px** (соотношение **4:5**) |
| Формат файла | PNG / JPEG |

Master 3×2 — только способ **сэкономить бюджет** (1 вызов Runware). На публикацию уходят отдельные слайды 1080×1350.

---

## Instagram

| | |
|--|--|
| **Рекомендуемый размер** | 1080×1350 (4:5) portrait |
| **Наш формат** | ✅ **Подходит идеально** |
| Карусель | до 10 слайдов; 6 — ок |
| Музыка | Graph API / Make **не добавляют** музыку → ручной шаг в приложении IG |

Источник: Meta / Instagram carousel specs (portrait 4:5 для feed carousel).

---

## TikTok (photo carousel через Zernio)

По [документации Zernio TikTok](https://docs.zernio.com/platforms/tiktok):

| | |
|--|--|
| **Рекомендуемый aspect** | **9:16** |
| **Авто-ресайз Zernio** | → **1080×1920** px |
| **Наш 4:5 (1080×1350)** | ⚠️ **Работает**, но TikTok/Zernio **пережмут/дополнят** до 9:16 (поля или кроп — на стороне TikTok) |
| Музыка | `auto_add_music: true` в API — TikTok ставит **рекомендованный** трек; **вручную сменить** в приложении после публикации |

### Вывод

- **Instagram** — 1080×1350, менять не нужно.
- **TikTok** — нативнее 1080×1920 (9:16). Для идеального вида в TT можно позже добавить вариант экспорта `slides/tiktok/` с полями 4:5→9:16 (P0: один размер для обеих сетей + ручная смена музыки в TT).

## Сравнение

```text
Instagram (4:5)          TikTok native (9:16)
┌──────────┐             ┌──────────┐
│          │             │          │
│  слайд   │             │          │
│          │             │  слайд   │
└──────────┘             │          │
 1080×1350                │          │
                           └──────────┘
                            1080×1920
```

Наш master 3×2 → slice 1080×1350 — **оптимален для IG**; для TT — приемлемый компромисс до отдельного 9:16 экспорта.
