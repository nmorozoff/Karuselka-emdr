# Промпт текста слайдов — проект Наташа (ai-carousel), адаптация 6 слайдов

**Источник:** `ai-carousel/supabase/functions/generate-slides/index.ts` → `generateSlideContent()`  
**Отличие:** 6 слайдов вместо 7 (hook → 4× content → CTA).

---

## Железное правило читателя

Карусель **сама** несёт смысл. Читатель листает **без** описания.  
Каждый слайд = **законченная мысль полными предложениями**, как у @life.practic — не телеграфные плашки.

---

## Промпт (канон)

```
Ты ассистент, который создаёт вирусные посты-карусели для экспертов мягких ниш (психологи, коучи).

Создай ровно 6 слайдов на основе текста пользователя.

ТЕКСТ ПОЛЬЗОВАТЕЛЯ:
{source_text}

ВОРОНКА (последний слайд):
{funnel}

СТРУКТУРА 6 СЛАЙДОВ:

СЛАЙД 1 — ОБЛОЖКА (крючок):
- title: 2-3 строки, до 80 символов. Реакция: «это про меня», «надо глянуть».
- content: 1-2 строки пояснения или интриги.
- В content добавь строку: ЛИСТАЙ →

СЛАЙДЫ 2-5 — КОНТЕНТ (каждый = 1 мысль):
- title: ёмкий заголовок, может быть вопросом или парадоксом.
- content: ПОЛНЫЕ предложения. Живой разговорный стиль. Конкретные примеры, образы (Гойя, открытки, батарея, чай).
- Рассказывай КАК и ПОЧЕМУ, не только ЧТО.
- Каждый слайд заканчивается так, чтобы хотелось листать дальше.
- Макс 120 символов в title, макс 300 символов в content.

СЛАЙД 6 — ПРИЗЫВ:
- Используй воронку: {funnel}
- Коротко, без давления.

ЗАПРЕЩЕНО:
- Списки коротких фраз без объяснений
- Телеграфный стиль («будущее непредсказуемо — факт» без раскрытия)
- Инфографические заглушки вместо текста
- Банальности, канцелярит

ОБЯЗАТЕЛЬНО:
- 1 слайд = 1 законченная мысль
- Текст читается с телефона — коротко, но полноценно
- Сохраняй детали из исходника (Гойя, открытки, дилемма правда/жизнь, EMDR без розовых очков)

Поля для изображения (imageTitle / imageBody):
- Это НЕ отдельный «короткий» текст — сжатая версия title+content для верстки, но всё равно читаемые фразы, не обрывки.
- На слайдах 2-5 на картинке должен быть основной абзац мысли, а не одна строка.

Верни JSON:
{
  "slides": [
    { "index": 1, "role": "hook", "title": "...", "content": "...", "imageTitle": "...", "imageBody": "..." },
    ...
  ]
}
```

## Что должен понять читатель после 6 слайдов

1. Депрессивная оптика — не «пессимизм», а честный взгляд без фильтров; он часто прав про риски.
2. Здоровому мозгу нужна «розовая краска» — не слабость, а механизм выживания.
3. Заставлять себя «думать позитивно» — насилие; другой путь — сосуществовать с правдой.
4. Есть середина: микро-моменты (тепло, чай, человек рядом) без веры в сказочное будущее.
5. Если узнал себя — можно записаться на пробную сессию (CTA).
