# Минимализм — Bold Editorial (pair 2)

Визуальная система для **6 слайдов**, master **3×2** (3240×2700 @ 4K) → нарезка на 6 панелей **1080×1350** (4:5).

Источник: `carousel-prompt-template.md` («Bold Editorial»), адаптировано под пайплайн Каруселька.

---

## MASTER CANVAS (один запрос Runware / GPT Image 2)

- Один seamless master: **сетка 3 колонки × 2 ряда**, 6 равных панелей без видимых швов между слайдами
- Каждая панель — отдельный слайд карусели Instagram 4:5
- Единый стиль на все 6 панелей: один фон, одна типографика, одна система нумерации
- Все надписи **только на русском**
- Без водяных знаков, без UI Instagram, без mockup телефона

## БАЗОВАЯ СПЕЦИФИКАЦИЯ ПАНЕЛИ (одинаково на всех 6)

- Соотношение каждой панели: **4:5** (1080×1350)
- Фон: сплошной тёплый кремовый **#F2EDE3**, без градиентов, без текстур
- Типографика: жирный гротеск (стиль Inter Black / Unbounded Bold), заголовки — **КАПСОМ**
- Номер слайда: крупная чёрная цифра слева сверху (`01`…`06`), под ней — короткий рукописный красный мазок-подчёркивание
- Счётчик прогресса: серая капсула справа сверху, формат `N/6`
- Безопасная зона ~80px от краёв панели
- Эксперт (Наталья Морозова): **опционально** на hook-панели — спокойная поза, без наигранной мимики; на остальных панелях — без фото или микро-портрет

## ЦВЕТОВАЯ ЛОГИКА

- **Красный #C0392B** — проблема / старый паттерн / «было»
- **Зелёный #2E7D4F** — решение / новое состояние / «стало»
- **Чёрный** — основной текст
- Чувствительные темы (травма, насилие, острое горе): не «красный = вы неправы»; мягче «было / стало», «до / после переработки». Красный — маркер прежнего состояния без осуждения.

## ИКОНКИ

- Плоские line-icon в кружке с лёгкой заливкой (розово-красный / зелёный по смыслу)
- Один смысловой объект на иконку
- Примеры: компас — понимание; молния — действие; щит+галка — безопасность; сломанное сердце — боль; ракета/флаг — цель; речевой пузырь — слова; мишень — точность; документ — фиксация

## ТИПЫ ПАНЕЛЕЙ (по смыслу слайда из copywriter)

### A — HOOK (панель 1, верхний левый угол master)
- Крупный заголовок, ключевое слово красным
- Опционально чуть затемнённый фон для контраста
- Внизу — короткая интрига («узнаете себя — читайте дальше»), без прямого CTA

### B — ДВА ПУТИ / КОЛОНКИ
- Две колонки, разделитель, «или» в центре
- Левая красная, правая зелёная; иконки-кружки, стрелки вниз
- Внизу ✗ слева, ✓ справа — без давления

### C — ФЛОУ-ДИАГРАММА
- 4–5 блоков со стрелками; пунктирная зелёная ветка к выводу

### D — ПРОСТОЕ X/✓
- Крупные ✗ и ✓, минимум декора

### E — INSIGHT-БЛОК
- Утверждение по центру; рамка с лампочкой и пояснением внизу

### F — СТАТИСТИКА
- Большой процент в круге + контрастная цифра; вывод в рамке

### G — CTA (панель 6, нижний правый угол master)
- Зелёный мазок-баннер, слово-триггер КАПСОМ (ЗАПИСЬ / ПОДРОБНЕЕ)
- 2–3 строки: «загляните в шапку профиля» / хайлайтс — **не** «напишите в комментариях»
- Line-art внизу: два кресла и столик с растением

## РАСКЛАДКА НА MASTER 3×2

```
[01 Hook]     [02]          [03]
[04]          [05]          [06 CTA]
```

Панели читаются слева направо, сверху вниз. Текст каждой панели — строго из `CAROUSEL_SLIDE_COPY.json` для variant-b.

## ПРАВИЛА ТЕКСТА (психология)

- Не «лечить/лечение/вылечить» → «терапия», «работа с…», «проработка»
- Без драматизации и пугающих формулировок
- Заголовок ≤ 8–10 слов; тело — 2–3 предложения или 3–5 пунктов
- Тон тёплый, уверенный, без токсичной мотивации

## ЗАПРЕТЫ ГЕНЕРАЦИИ

- Не смешивать стили между панелями
- Не обрезать текст по краям панели
- Не добавлять логотипы соцсетей
- Не дублировать один и тот же блок на нескольких панелях
- CTA без обещаний результата — только приглашение

- [ ] Красный/зелёный по смыслу
